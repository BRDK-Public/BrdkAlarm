Configuration of a new alarm to the list
    IN Name STRING[255]   Name of an existing alarm configuration. Leave empty to configure an alarm at runtime using AlarmConfig input
    IN Condition BOOL   State of the alarm condition. If TRUE the alarm will be set after the delay if not inhibitted. If FALSE the alarm will be reset
    IN Delay TIME   Alarm Delay. The alarm will be triggered after the delay if Condition is TRUE and Inhibit is FALSE
    IN Inhibit BOOL   Inhibits the alarm from being set. If already active it will be reset
    IN Acknowledge BOOL   Acknowledge the alarm
    IN Confirm BOOL   Confirm the alarm
    IN ErrorReset BOOL   Resets error(s) on the MpComConfigBasic if it fails to read or save alarm config
    OUT Active BOOL   Active when the function block is enabled
    OUT AlarmActive BOOL   TRUE if alarm has been set and FALSE if alarm has been reset
    OUT InstanceID UDINT   InstanceID of the alarm if Active
    OUT StatusID DINT   ID of the status from MpComConfigBasic
    OUT Info MpAlarmXCfgListAlarmType   Alarm config info
    OUT Error BOOL   An error is active and must be reset
    VAR internal BrdkAlarmControlInternalType   Internal type
    VAR state UINT   Internal state of the function block
